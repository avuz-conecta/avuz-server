---
title: "Como usar uma checklist no cartão"
description: "Divida uma tarefa em subtarefas com uma checklist marcável dentro do cartão."
sidebar:
  order: 8
capturedForVersion: "33.0.8"
---

1. Abra o cartão (ex.: **Preparar evento**) e clique no campo **Descrição** para começar a escrever.
2. Clique no botão **Listas** na barra de formatação e escolha **Lista de tarefas** para criar uma checklist.
3. Digite cada subtarefa (ex.: "Reservar local", "Enviar convites", "Confirmar buffet") e pressione Enter entre elas para criar novos itens.
4. Clique na caixa de seleção ao lado de um item (ex.: **Reservar local**) para marcá-lo como concluído.
5. O cartão mostra o progresso da checklist (ex.: 1/3) direto no painel, sem precisar abrir os detalhes.
