---
title: "Como criar um cartão"
description: "Adicione cartões a uma lista — cada cartão é uma tarefa."
sidebar:
  order: 3
capturedForVersion: "33.0.8"
---

1. Abra um painel com listas (ex.: **Sprint de Vendas**) e clique em **Adicionar cartão** no topo da lista (ex.: **A fazer**).
2. Digite o título do cartão (ex.: **Preparar proposta comercial**) no campo **Nome do cartão**.
3. Pressione **Enter** para criar o cartão; ele aparece na hora dentro da lista.
4. Clique no cartão para abrir seus detalhes.

:::tip
Clique no cartão para adicionar descrição, prazo e responsável.
:::
