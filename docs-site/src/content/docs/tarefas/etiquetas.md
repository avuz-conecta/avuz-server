---
title: "Como usar etiquetas"
description: "Marque cartões com etiquetas coloridas para agrupar e filtrar tarefas."
sidebar:
  order: 6
capturedForVersion: "33.0.8"
---

1. Abra o cartão (ex.: **Criar peças gráficas**) para ver seus detalhes.
2. Clique no campo **Selecionar ou criar uma etiqueta…** para ver as etiquetas disponíveis.
3. Selecione uma etiqueta da lista (ex.: **Ação necessária**) para aplicá-la ao cartão.
4. A etiqueta colorida aparece no cartão, ajudando a identificá-lo rapidamente no painel.

:::tip
Crie suas próprias etiquetas nas configurações do painel.
:::
