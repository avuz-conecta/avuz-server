---
title: "Como mover cartões entre listas"
description: "Arraste um cartão de uma lista para outra conforme a tarefa avança."
sidebar:
  order: 5
capturedForVersion: "33.0.8"
---

1. Abra o painel (ex.: **Fluxo de Trabalho**) com o cartão que deseja mover (ex.: **Revisar contrato**) na lista **A fazer**.
2. Clique e segure o cartão, depois arraste-o para a lista de destino (ex.: **Em andamento**).
3. Solte o cartão sobre a lista para posicioná-lo lá.
4. O cartão agora aparece dentro de **Em andamento**, refletindo a nova etapa da tarefa.
