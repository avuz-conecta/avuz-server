---
title: "Como criar um painel"
description: "Crie um painel para organizar tarefas de um projeto ou equipe."
sidebar:
  order: 1
capturedForVersion: "33.0.8"
---

1. Abra o **Tarefas** e clique em **Adicionar painel** no menu lateral.
2. Escolha uma cor para o painel e clique em **Escolher**.
3. Digite um nome para o painel (ex.: **Projeto Marketing**) e confirme em **Salvar painel**.
4. O painel é criado na hora e abre pronto para receber listas e cartões.

<video src="/assets/tarefas/criar-painel.mp4" muted autoplay loop playsinline controls></video>

:::tip
Use um painel por projeto ou por equipe para manter as tarefas organizadas.
:::
