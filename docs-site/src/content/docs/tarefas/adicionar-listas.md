---
title: "Como adicionar listas"
description: "Crie colunas (listas) no painel para separar as etapas do trabalho."
sidebar:
  order: 2
capturedForVersion: "33.0.8"
---

1. Abra um painel sem listas (ex.: **Lançamento do Produto**); o painel mostra o campo **Nome da lista**.
2. Digite um nome (ex.: **A fazer**) e clique em **Adicionar lista** para criar a primeira lista.
3. Clique em **Adicionar lista** no topo do painel para criar as próximas listas (ex.: **Em andamento**, **Concluído**).
4. Cada lista aparece como uma nova coluna no painel, pronta para receber cartões.

:::tip
Um fluxo comum é usar as listas A fazer, Em andamento e Concluído.
:::
