---
title: "Como criar um quadro"
description: "Crie um quadro para organizar tarefas de um projeto ou equipe."
sidebar:
  order: 1
capturedForVersion: "33.0.8"
---

1. Abra o **Tarefas** e clique em **Adicionar painel** no menu lateral.
2. Escolha uma cor para o quadro (ex.: **Azul Nextcloud**) e clique em **Escolher**.
3. Digite um nome para o quadro (ex.: **Projeto Marketing**) e confirme em **Salvar painel**.
4. O quadro é criado na hora e abre pronto para receber listas e cartões.

<video src="/assets/tarefas/criar-quadro.mp4" muted autoplay loop playsinline controls></video>

:::tip
Use um quadro por projeto ou por equipe para manter as tarefas organizadas.
:::
