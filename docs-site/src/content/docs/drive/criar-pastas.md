---
title: "Como criar pastas"
description: "Organize seus arquivos em pastas dentro do Drive."
sidebar:
  order: 2
capturedForVersion: "33.0.8"
---

1. Abra o **Drive** e clique em **Novo** na barra superior da lista de arquivos.
2. Selecione **Nova pasta**.
3. Digite um nome para a pasta (ex.: **Projetos**) e clique em **Criar**.
4. A pasta é criada na hora e aparece na lista de arquivos, pronta para receber documentos.

<video src="/assets/drive/criar-pastas.mp4" muted autoplay loop playsinline controls></video>

:::tip
Arraste arquivos para dentro de uma pasta para movê-los rapidamente.
:::
