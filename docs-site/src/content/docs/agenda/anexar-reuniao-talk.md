---
title: "Como anexar uma reunião do Talk a um evento"
description: "Adicione uma sala de vídeo do Talk ao evento — todos entram pelo mesmo link na hora."
sidebar:
  order: 9
capturedForVersion: "33.0.8"
---

1. Abra a **Agenda** e clique em **Criar novo evento**.
2. Digite um título para o evento (ex.: **Reunião com cliente**).
3. Clique em **Mais detalhes** para abrir as opções completas do evento.
4. Clique em **Adicionar conversa do Talk** para anexar uma sala de vídeo ao evento.
5. Escolha **Criar conversa privada** para gerar uma nova sala do Talk para essa reunião.
6. O link da reunião do Talk aparece no evento. Clique em **Salvar** para confirmar.
7. Todos os convidados encontram o link da reunião direto no evento, na hora de entrar.
