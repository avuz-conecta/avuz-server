---
title: "Como definir seu status de disponibilidade"
description: "Avise os colegas se você está disponível, ausente ou ocupado."
sidebar:
  order: 2
capturedForVersion: "33.0.8"
---

1. No menu do seu perfil (avatar, canto superior direito), clique em **Definir status**.
2. Selecione **Fora** para indicar que você está fora do computador.
3. Escolha uma mensagem, como **Em reunião**, e clique em **Definir mensagem de status**.
4. Seu novo status aparece imediatamente no menu do perfil.

<video src="/assets/minha-conta/status-disponibilidade.mp4" muted autoplay loop playsinline controls></video>

:::tip
Um status "Não perturbe" silencia as notificações de chamada.
:::
