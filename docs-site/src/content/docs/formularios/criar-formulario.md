---
title: "Como criar um formulário"
description: "Crie formulários e pesquisas para coletar respostas."
sidebar:
  order: 1
capturedForVersion: "33.0.8"
---

1. Abra os **Formulários** e clique em **Novo formulário**.
2. Digite um título para o formulário (ex.: **Pesquisa de satisfação**).
3. Clique no campo **Descrição** para confirmar o título.
4. O formulário é salvo automaticamente e o editor fica pronto para adicionar perguntas.

:::tip
Comece pelo título — depois adicione as perguntas.
:::
