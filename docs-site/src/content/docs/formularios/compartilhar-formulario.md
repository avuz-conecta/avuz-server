---
title: "Como compartilhar um formulário"
description: "Gere um link para enviar o formulário e coletar respostas."
sidebar:
  order: 4
capturedForVersion: "33.0.8"
---

1. Abra o formulário (ex.: **Pesquisa de opinião**) e clique em **Compartilhar**.
2. Na aba **Compartilhamento**, clique no **+** ao lado de **Compartilhar link** para gerar um link público.
3. O link aparece na lista. Clique em **Copiar para área de transferência** para copiar o endereço.
4. Envie o link copiado (e-mail, mensagem) — qualquer pessoa com ele pode abrir o formulário e responder.

<video src="/assets/formularios/compartilhar-formulario.mp4" muted autoplay loop playsinline controls></video>

:::tip
Qualquer pessoa com o link pode responder, sem precisar de conta (se você permitir).
:::
